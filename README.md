# Research Defense Mockup

Interactive mockup สำหรับการนำเสนอสอบวิจัยเรื่องการพัฒนาเว็บแอปพลิเคชันเพื่อบริหารจัดการและสื่อสารข้อมูลของศูนย์พัฒนาเด็กเล็ก เทศบาลเมืองบางใหญ่ จังหวัดนนทบุรี

> ข้อมูลทั้งหมดในระบบเป็นข้อมูลจำลองสำหรับการสาธิต ไม่ใช่ข้อมูลเด็กจริง และไม่มีการเชื่อมต่อ Supabase หรือ LINE

## Run locally

เปิด `index.html` หรือรัน `python -m http.server 3000` แล้วเข้า `http://localhost:3000`

## Deployment

Repository นี้ออกแบบเป็น static site และ deploy บน Vercel ได้โดยตรง
